# 物业不动产租赁管理系统

面向物业公司不动产（房屋 / 商铺）租赁全流程管理系统：**合同管理、客户档案、房源管理、收费管理、发票管理、审批流程、工单巡检、钉钉对接、报表统计**，支持多项目、多楼栋、多房间与租赁变更 / 退租 / 押金 / 水电杂费 / 合同到期预警等复杂现场业务。

* **零依赖**：只用 Node.js 内置模块，**不需要安装任何第三方库、不需要数据库**
* **数据本地**：全部数据以 JSON 文件保存在 `data/` 目录，可随时备份、迁移
* **PC 端为主 + 移动端适配**：PC 端完整功能，移动端面向巡检 / 抄表 / 待办（夜班手机录入）

---

## 一、启动方式

### 方式 1：双击启动（推荐）

```
双击  启动系统.bat
```

浏览器会自动打开 <http://localhost:8080/>

### 方式 2：命令行

```bat
cd /d Y:\物业不动产租赁管理系统
node server.js
```

指定端口：`node server.js 9000`

> 环境要求：本机已安装 Node.js 18 及以上（当前环境为 Node 22）。
> 若提示 `node 不是内部或外部命令`，请改用方式 1 的启动脚本（脚本内置了本机 Node 路径探测）。

| 端 | 地址 | 用途 |
|---|---|---|
| PC 端 | http://localhost:8080/ | 全部业务功能 |
| 移动端 | http://localhost:8080/m.html | 待办工单、巡检录入、抄表录入、提醒中心 |

### 多台电脑部署（一个服务器 + N 台客户端电脑）

**推荐架构：只在一台机器上跑服务，其他电脑用浏览器访问。**

```
        ┌─────────────────────────────┐
        │  服务器电脑（跑 node server.js）│   ← 唯一持有 data/ 数据的机器
        │  数据目录：Y:\...\data        │
        └──────────┬──────────────────┘
                   │  局域网（同一路由器 / 同一网段）
     ┌─────────┼─────────┬─────────┐
  办公室PC   财务PC    工程PC    总经理笔记本
  浏览器访问  浏览器访问  浏览器访问   浏览器访问
  各自账号登录 → 看到各自权限菜单
```

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 在服务器电脑上执行 `启动系统.bat` 或 `node server.js` | 启动横幅会直接打印**局域网地址**，例如 `http://192.168.1.200:8080/` |
| 2 | 在服务器电脑放行防火墙端口 | 首次启动需允许 TCP 8080 入站（管理员身份运行 PowerShell：`New-NetFirewallRule -DisplayName "物业系统8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow`） |
| 3 | 其他电脑**不需要装任何东西** | 打开浏览器，输入 `http://192.168.1.200:8080/` 即可 |
| 4 | 建议把地址存为浏览器书签 / 桌面快捷方式 | IP 可能变动，建议在路由器里给服务器做 IP 固定（DHCP 静态分配） |
| 5 | 每人用**自己的账号**登录 | 登录后菜单与按钮按角色权限自动裁剪 |

**移动端**：手机连同一 WiFi，浏览器打开 `http://服务器IP:8080/m.html`（可"添加到主屏幕"当 App 用）。

**几台电脑能看到什么**：由登录账号决定，与电脑数量无关。

| 账号 | 电脑端可见模块 |
|---|---|
| `admin` | 全部 14 个模块 |
| `kefu` | 驾驶舱、客户、合同、收费（只读）、工单、报表 |
| `caiwu` | 驾驶舱、收费、发票、报表、人事薪酬、审批 |
| `gongcheng` | 驾驶舱、房源、工单巡检、巡更检查、人事（考勤） |
| `renshi` | 组织权限、人事薪酬、审批 |

**在线会话管理**：系统设置 →「在线会话」可查看当前谁在线、从哪几台电脑（IP + 登录时间）登录，并可「全部下线」（用于员工离职、账号泄露、异常登录）。登录状态存在服务端 `data/sessions.json`，**服务重启后不掉线**；同一账号可在多台电脑同时登录，24 小时后自动失效。

> ⚠️ **不要在两台电脑上都启动服务**。本系统的数据是「内存缓存 + 全量写 JSON」的单进程独占存储，两套服务同时写同一个 `data/` 目录会互相覆盖数据。
> 系统已内置**单实例锁**：第二个实例启动时会直接报错并拒绝运行，提示被哪个 PID / 哪台机器占用。
> 强杀进程（任务管理器结束任务）会留下锁文件，重启时会自动识别为失效锁并接管，无需手工清理。

**同一台机器要跑多套互不干扰的数据**（例如测试环境与正式环境分开）：

```bat
set DATA_DIR=D:\plm-test\data
set UPLOAD_DIR=D:\plm-test\uploads
set EXPORT_DIR=D:\plm-test\exports
node server.js 8090
```

| 环境变量 | 默认值 | 作用 |
|---|---|---|
| `DATA_DIR` | `<程序目录>\data` | 数据库目录 |
| `UPLOAD_DIR` | `<程序目录>\uploads` | 附件目录 |
| `EXPORT_DIR` | `<程序目录>\exports` | 导出文件目录 |
| `PORT` | `8080` | 监听端口（也可用命令行参数 `node server.js 9000`） |
| `PLM_FORCE=1` | — | 强制接管被占用的数据目录（确认是残留锁时用，有风险） |

**建议服务器电脑的设置**：
- 关闭自动睡眠 / 休眠，否则服务会中断，其他电脑无法访问
- 如需开机自启，把 `node server.js 8080` 加到「任务计划程序 → 触发器：计算机启动时」
- 定期把整个 `data` 目录复制到移动硬盘（详见「六、数据与备份」）
- 如果要暴露到互联网，请**务必**在前面加 Nginx + HTTPS 反向代理；直接用 http 暴露到公网，登录密码是明文传输的

## 四、功能地图

### 1. 组织架构与权限
* 预设部门：招商部 / 客服部 / 财务部 / 人事部 / 工程运维部 / 总经办；岗位含 **进线发票、出纳发票**
* 13 个角色 × 40+ 权限点，**数据范围四级隔离**（全部 / 本部门 / 所属项目 / 仅本人经办）
* 支持新增部门、自定义岗位与角色
* **多级审批**：合同审批 2 级（招商经理·价格审核 → 财务经理·租金审核），**免租期 ≥ 2 个月**自动追加总经理·免租期审核

### 2. 房源（不动产）管理
* **多项目**：成功新时代 / T3，每个项目独立房源与独立招商端口
* **跳层编号**：4 楼显示 `3A`、14 楼显示 `13A`（可自定义映射）
* **房号自定义**：`08-10 号`合并为一套房源；一套房源可拆分为 `01-A / 01-B` 分给多个客户（合租）
* 房间**合并 / 拆分**、后台修改房间属性（面积、楼层类型、业态、状态）
* 产权证书 / 不动产权证信息、**CAD 图纸**附件、配套信息（中央空调、消防楼层）
* **跨楼栋迁移**：如 10 栋 → 20 栋，**历史账单、水电费用、合同全部跟随迁移**并留痕

### 3. 客户档案
* 企业 / 个人客户，营业执照、法人身份证、银行账户**全资料附件上传**
* 客户**全历史租赁记录**、收款记录、开票记录一键查看
* **风险标记**：逾期风险 / 违约风险 / 重点关注（个人客户违约风险提示）
* **多租户**：一套房源多个客户，账单支持**合并核算 / 分开核算**

### 4. 合同管理（核心）
* 合同模板与在线比对、合同录入（出租方 / 承租方 / 信用代码 / 房号 / 租金单价含税与不含税 / 面积 / 租期 / 免租期 / 押金 / 各项费用）
* 费用项：租金、物业费、电费、水费、室内保洁费、维修费（含专项维保）
* **合同状态**：正常履约 / 退租 / 变更 / 逾期 / 终止 / 审批中 / 审批驳回
* **合同变更留痕**：每次变更生成记录并版本号 +1
* **退租管理**：生成退房单据 → 水电读数核验 → 欠费核算 → 押金退回流程
* **到期预警**：到期前 3~6 个月预警、提前一周提醒、提前一天再次提醒；每 3~6 个月**履约复核**
* 一键导出**合同清单**与**出租明细**

### 5. 收费管理（核心）
* **按月生成账单**，月末记账；租金与各项杂费**分项列示**（数量 / 单价 / 金额 / 税率 / 税额）
* 支持**账单跨月**、每日收款汇总、月度费用汇总
* **电费专项**：
  * 电表号 / 抄表日期 / 表底读数管理
  * **抄表错误修正** → 自动重算当期电费并生成差额
  * **空置房基础电费**（5~10 元/月，标记为内部成本不计入催收）
  * **整层公摊电费分摊**（按面积 / 平均 / 用量三种方式，自动写入各房间账单）
  * **偷电监控**：单位面积用电异常、已租房间零用电自动预警
* **收款管理**：收款登记（核对房号 / 电表号）、欠费催收跟进
* **费用变更**：每月可调整房间与单价，租金单价变更同步后续账单
* **押金管理**：已收 / 在管 / 待退 / 已退全流程跟踪

### 6. 发票管理
* 增值税**普票 / 专票**
* **按内容分开开票**：租金一张票、物业费一张票、电费一张票、杂费（维修 / 维保）单独开票、保洁费单独开票
* **开票校验**：租户发票信息是否齐全、开票金额与账单余额核对、风险客户提示
* 4 套发票模板、发票台账（可导出）、发票作废回冲

### 7. 钉钉对接
* 单据审批、合同审批**在钉钉内完成**（审批回调接口 `/api/dingtalk/callback`）
* 消息推送：**合同到期提醒、欠费提醒、巡检工单提醒**
* 配置 AppKey / AppSecret / AgentId 后启用；默认 `mock` 模式（推送写入本地消息队列，便于先验证流程）

### 8. 巡检 / 运维工单
* 巡检任务：**每日巡检、月度巡检、合同履约巡检（3~6 个月复核）、每月一次电表抄表巡检**
* **7 楼中央空调每日白班巡检**，**消防楼层重点标记**（自动置为紧急）
* 工单管理：维修 / 巡检 / 抄表 / 消防 / 空调，现场情况记录 + **拍照上传**
* 移动端录入，适配夜班值班场景

### 9. 报表、统计与导出
* 报表：房源统计表、客户台账、收费台账、合同台账（合同清单）、出租明细、发票台账、收款明细、押金台账
* **支持 CSV / Excel 双格式批量导出（几千条记录）**，导出字段包含**通讯地址**
* 统计指标：各项目平均单价（含税 / 不含税）、每日收款汇总、月度费用汇总、空置房间统计、欠费客户清单

### 10. 人事管理（员工档案）
* **员工档案**：工号、身份证、学历、入职 / 转正 / 合同到期、通讯地址、紧急联系人、银行卡
* 关联系统登录账号、所属部门 / 岗位 / 项目 / 班制班次（行政班 / 早班 / 晚班 / 夜班）
* **薪酬档案**：基本工资 + 岗位工资 + 绩效工资×绩效系数 + 交通 / 餐费 / 通讯 / 夜班补贴 + 全勤奖
* **社保档案**：缴费基数、公积金比例、专项附加扣除（子女教育 / 房贷 / 赡养老人）
* 劳动合同到期预警（60 天内自动进入提醒中心）

### 11. 考勤管理
* **排班考勤**：按员工班次批量生成月度考勤，周末自动休息，夜班「做二休一」
* **打卡 / 补卡**：上班 / 下班打卡自动判定迟到、早退、缺卡
* **考勤日历**：单人单月可视化（正常 / 迟到 / 请假 / 出差 / 旷工 / 休息）
* **月度汇总**：应出勤、实出勤、出勤率、迟到次数、旷工、请假（区分全薪 / 无薪）、加班工时
* **修正留痕**：考勤异常可人工修正，自动记录修改前后快照

### 12. 请假 / 加班
* **请假单**：事假 / 病假 / 年假 / 调休 / 婚假 / 产假 / 丧假 / 工伤假 / 出差 / 外勤，审批后**自动回写考勤**
* **计薪规则**：年假调休全薪、病假 80%、事假无薪（自动折算扣款天数）
* **加班单**：工作日 1.5 倍 / 休息日 2 倍 / 法定节假日 3 倍，补偿方式可选「加班费」或「调休」

### 13. 薪资核算（核心）
* **一键生成**：按当月考勤、请假、加班自动核算全员工资，支持先「试算」再落库
* **工资构成**：基本 + 岗位 + 绩效 + 各项补贴 + 加班费 + 全勤奖 − 事假 / 病假 / 旷工 / 迟到扣款
* **社保公积金**：按险种分项计算个人 / 单位承担，基数自动**封顶保底**
* **个人所得税**：国家税务总局 **2019 年起累计预扣预缴法**（7 级超额累进，自动跳档、自动扣减已预缴）
* **工资条**：收入项 / 扣款项 / 社保明细 / 个税累计推导过程完整展示
* **发放**：单条发放或批量发放（银行代发），**已发放记录禁止删除**
* 部门薪酬分布、近 6 个月人力成本趋势（应发 + 单位社保）
* 导出工资表 / 考勤月报 / 员工名册（CSV / Excel）

### 14. 巡更检查（由「巡更检查小工具」整合）
* **巡更点位（地点卡）**：卡号 / 名称 / 路线 / 路线内顺序，按楼层自动排序（18F→1F→负层→设备房）
* **巡更人员（人员卡）**：卡号 / 姓名 / 班次（夜班 / 白班）
* **巡查记录导入**：直接上传巡检器导出的 `.xls / .xlsx / .csv`（**零第三方依赖自研解析，不需要装 Python / xlrd / openpyxl**），支持追加与覆盖两种模式，导入批次留痕
* **夜班分析（核心）**：夜班时段 **当天 18:30 ~ 次日 06:30**，以「夜班起始日」为班次日；17:30~18:00 计入当日、06:00~06:30 计入前一日
* **漏检判定**：应巡点位 vs 实巡点位，逐日列出漏检点位清单与覆盖率
* **班次日报**：巡检明细 + 遗漏汇总（对齐原小工具的两张表导出口径）
* **月度汇总**：班次数 / 应巡点次 / 实巡点次 / 漏检点次 / 覆盖率 / 全巡率、**漏检 TOP10 点位**、人员当班统计
* **白班口径**：同一套规则按自然日统计，可与夜班对照
* **导出**：日报 / 月报（Excel 双表）/ 巡查记录（CSV 带 BOM）
* **移动端**：`/api/patrol/mine` 按当前登录人汇总近 30 天出勤

### 15. 收入台账（按公司真实在用的「月表格」体系构建）

> 依据 `Y:\物业实际使用的报表及合同` 下 16 个真实文件逐条对齐，详见 `docs/真实业务差距清单.md`

**收入日报（12 类科目，与真实日报表头一一对应）**
* 定金 / 新签租金物业 / 续费租金物业 / 照明电费 / 空调电费 / 月租停车费 / 临时停车 / 套内保洁 / 保洁部卖废品 / 会议室 / 中介费 / 其他 + 日汇总列
* 收款单自动归科目：**以关联账单的 `bill.items` 为第一依据**（收款单自身不带费用明细），判定顺序 停车 → 会议/中介 → 租金物业 → 保洁 → 电费 → 水费
* 按天铺满整月，可导出 CSV

**停车费（表3）**
* 车位档案 + 停车费明细台账；**月租车位 396 元/个/月**、临时停车按次/小时
* **金额由服务端算**：`车量 × 单价 × 数量`，前端只读，新增与修改都会重算
* 按月汇总区分「月租 / 临时」两类

**上期尾款（表10）**
* 单元号 / 公司 / 摘要 / 金额 / 收入日期 / 余额，未结清 / 已结清
* 汇总区分未结清与已结清，未结清部分红色高亮

**支出台账（表8）**
* 6 类支出：物业费用 / 日常费用 / **预提款** / 招商费用 / 其他 / 垫付支出，含收款人与支付途径
* **季度汇总**：按月横排各类金额
* **预提款分段（核心）**：预提按季一次性计提，但看数必须能**拆到月**看实际支出 —— 分段表同时给出「预提款支出 / 实际支出 / 合计」三列，并保证 `预提 + 实际 = 合计` 的恒等关系

**表9 其他费用（六张台账）**
* 与真实文件 `（表9）其他费用.xlsx` 的 6 个工作表一一对应：**其他收入 / 其他支出 / 中介费 / 会议室收入 / 垫付收入 / 垫付支出**
* 每张台账：上方「按月分段小计」条，下方明细台账
* **中介费**独有字段：收款单位/人、单据编号、单元号、面积、费用总金额、已付金额、未付金额、发票 —— 其中**未付金额由服务端算**（费用总金额 − 已付金额），不让人手填错
* **会议室收入**独有字段：使用日期、使用时间、税票情况
* 可导出为 **6 个 sheet 的多表 Excel**

**月表格一键生成（7 张表 / 16 个 sheet）**
| 表 | sheet |
|---|---|
| 表1 房租 | 本月 / 上月 / **差额** |

| 表10 上期尾款 | 上期尾款 |
| 收入日报统计表 | 日收入（12 类 + 日汇总） |

**租金递增引擎**
* 支持合同原文的四种约定：**「不递增」/「第三年起每年递增 6%」/「每 2 年递增 10%」/ 固定租金**
* 复合计算 `base × (1+rate)^次数`，实测：基础 100 元、2026-01 起租、第三年起每年 6% → 100 / 100 / **106** / **112.36** / **119.1**
* 账单生成直接使用递增后单价，`buildBill` 返回 `escalate` 明细（当期单价 / 基准价 / 第几年 / 递增次数 / 说明）

**水电充值台账**
* 直接导入真实「缴费账单.xlsx」，**识别退费（负数金额）**，如「挪 20 元至空调表」
* **导入幂等**：按「时间 + 订单号 + 金额」去重，同一份账单重复导入不会重复入库（账单是按月重复导出的，没这层保护金额会逐月翻倍）
* 充值 / 退费分别统计，净额自动算出

### 常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动报「数据目录已被占用，拒绝启动」 | 已有一套服务在跑同一个 `data/` 目录。**这是保护机制，不要绕过**。若确认是残留锁（提示的 PID 已不存在），直接重启即可自动接管；或删掉 `data\.instance.lock` |
| 启动报「端口 8080 已被占用」 | 换个端口：`node server.js 8090`；或关掉占用程序 |
| 其他电脑打不开 `http://服务器IP:8080/` | ① 服务器防火墙未放行 8080（见「二、多台电脑部署」步骤 2）；② 两台电脑不在同一网段/路由器开了 AP 隔离；③ 服务器 IP 变了（用 `ipconfig` 查新 IP） |
| 其他电脑能打开但菜单是空的 | 该账号没有任何模块权限，用 `admin` 登录后到「组织权限 → 角色」分配权限 |
| 员工离职后账号还能登录 | 系统设置 →「在线会话」可强制下线；组织权限里把该用户状态改为「停用」则彻底不能登录 |
| 服务重启后大家要重新登录 | 不会——登录态存在 `data/sessions.json`，重启后自动恢复（这是 v2.0 起的行为） |
| 数据想整体挪到别的盘 | 停服务 → 复制整个 `data` 目录到新位置 → 用 `set DATA_DIR=新路径` 启动 |
